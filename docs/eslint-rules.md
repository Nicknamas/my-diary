# Правила ESLint на будущее

Правила импорта, о которых договорились при обсуждении архитектуры фронта.
Включать по мере появления структуры: `core → pages → domains → shared`.

## Уровни

1. Импорт только вниз: `core → pages → domains → src/shared`. Вверх и вбок нельзя.
2. `pages` не импортируют друг друга.
3. `src/shared` не импортирует ничего из `core`, `pages` и `domains`.

## Домены

4. Снаружи домена разрешён только его публичный API: `@domains/<name>` (`index.ts`).
   Глубокие импорты вроде `@domains/<name>/shared` или `@domains/<name>/block/...` разрешены только изнутри самого домена.
5. Граф зависимостей между доменами объявлен явно (список разрешённых направлений) и без циклов.
6. Относительные импорты не выходят за корень домена (`../../other-domain/...` запрещено).

## Поддомены

7. Соседние поддомены не импортируют друг друга.
8. Поддомен может импортировать `core` родителя, а `core` родителя поддомены — нет.
9. Выбор поддомена по типу живёт в `index.ts` родителя.

## Внутри домена

10. Направление слоёв: `block → model → api → shared` домена. Экранов в домене нет — их собирают `pages` из блоков домена.
    `block` может читать из `api` напрямую, если ему нужен только read-слой. Мутации и черновики — через `model`.
    Чтобы линтер мог это проверить, чтение и мутации в `api/` должны лежать раздельно (например, `api/queries` и `api/mutations`): тогда `block` разрешён импорт только из чтения.
11. `ui/` (глупые компоненты) не импортирует `api/`, `model/` и `block/`: только props и emits. `block` может использовать `ui`.

## Алиасы

12. `@shared` указывает только на глобальный `src/shared`.
13. Домены подключаются через один алиас с маской: `"@domains/*": ["src/domains/*"]`.
14. UI-кит импортируется только по имени пакета и только из его публичных экспортов.

## Инструменты

- `eslint-plugin-boundaries`: типы элементов (core, page, domain, subdomain, shared) и разрешённые направления (правила 1–9).
- `no-restricted-imports` с `patterns`: запрет глубоких импортов и относительных выходов за домен (правила 4, 6, 11).
- Поиск циклов: `import/no-cycle` или `dependency-cruiser`. Второй заодно рисует граф зависимостей.
